# IDEAsian Brand Guide

## Brand

**IDEAsian**

IDEAsian is a home for ideas becoming real things — design, making,
experimentation, problem-solving, and whatever comes next.

### Name styling

Always write the brand as:

**IDEAsian**

Not:
- Ideasian
- IdeaSian
- IDEASIAN

The capitalization is intentional: **IDEA + Asian**.

---

## Brand Architecture

IDEAsian is the parent brand.

Individual services and projects can live beneath it using a slash:

**IDEAsian / Print**

Future examples:

**IDEAsian / Design**  
**IDEAsian / Labs**

Web services may also use IDEAsian subdomains:

`print.ideasian.com`

---

## Logo System

The IDEAsian visual identity is based on the original I'm Alice
cat-eye glasses mark.

### Primary Logo

Glasses mark + IDEAsian wordmark.

### Wordmark

IDEAsian without the glasses mark.

### Brand Mark

Glasses mark alone.

Useful for:
- Favicons
- Social avatars
- Small UI elements
- App icons

### Logo Files

Brand assets live in:

`/assets/brand/logos/`

## Voice

IDEAsian should sound:

- Smart
- Approachable
- Curious
- Playful
- Direct
- Human

Technical knowledge should make things easier for people, not require
them to learn technical language first.

## IDEAsian / Print

**3D printing + custom fabrication**

IDEAsian / Print helps turn files, ideas, broken parts, prototypes,
props, and oddly specific problems into physical things.

### Current positioning

**You need a thing. I can make it real.**

Supporting language:

**3D printing without the 3D-printing homework.**

**3D printing • custom fabrication • weird problems solved**
